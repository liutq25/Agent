# 比赛演示脚本（DEMO，非课堂实验）

准备：启动 `启动知学.cmd`；在“模型设置”选择已配置的模型 API。无 API 时可用 Mock 模式演示固定核验题。所有演示使用虚构学生 ID，不要展示真实学生资料。

## A：结果错误与典型误区

在“对话学习”输入：`我认为顺序表可以按下标 O(1) 访问，所以在中间插入也是 O(1)。`

检查：Agent 先解释访问与插入的区别，再引用学生原话提出具体核验题；第二轮输入 `找到下标后就直接插入，不用移动。`，展示已证实的误区记录和证据。

## B：答案正确但理由错误

新建对话，输入：`已经知道前驱节点时，单链表插入是 O(1)，因为链表节点在内存里连续存放。`

检查：Agent 区分正确的复杂度结论与错误理由，针对“物理连续”追问。不能把最终数字正确等同于概念掌握。

## C：算法步骤首错

打开“算法轨迹”，选择“堆排序”并输入 `3,1,2`，按界面给出的参考轨迹填写一条故意错误的学生状态。检查“首次不同的一步”、参考状态和教师端“算法轨迹首错”记录。高级输入可演示全部 22 个工具。

## D：跨轮学习画像

沿用 A 的虚构学生，继续回答或另开会话再使用同一学生 ID，查看“学习画像”中的概念证据、误区状态变化。若 Docker 已就绪，完成两次代码练习以展示提示需求级别；否则明确展示沙箱不可用状态。切到“教师概览”查看班级聚合。所有数值仅为原型状态，不代表教学实验结论。
