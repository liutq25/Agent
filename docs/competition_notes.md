# 比赛信息核验（2026-09-27）

第二届全国高校“启真问智”教育教学人工智能大赛由浙江大学主办，赛道含教育教学智能体。参赛团队由在职教师和全日制本科生共同组成，原则上不超过 4 人。智能体作品须基于国内通用大模型和平台工具，聚焦真实教学场景，并体现教学效率、个性化学习及学习评价。评分关注创新性、教学应用价值、技术实施质量、用户体验与可推广性、真实落地效果和“师-生-机”协同。

来源：温州商学院教务部 2026-08-11 通知：<https://jw.wzbc.edu.cn/Art/Art_188/Art_188_139832.aspx>。

南方医科大学转发的预通知写明：报名截止 2026-09-15，作品提交截止 2026-09-30；智能体赛道需 PPT 转 PDF（≤50 MB）、至少 5 分钟且 ≤200 MB 的 MP4 演示视频，学校和姓名等个人信息不得出现在材料中。提交要求可能因学校校赛或官网更新而变化，最终以参赛团队所属学校及大赛官网通知为准。目前日期已过所列报名期限，需由参赛团队确认报名资格及校赛结果。

来源：南方医科大学教学发展中心 2026-07-16 预通知：<https://portal.smu.edu.cn/ctd/info/1073/38119.htm>。
