# 诊断题库公开参考资源

公开材料仅用于查证知识点与设计题型；不得把公开练习的答题数据写成真实学生数据，也不能把自动改写题直接标记为课程教师已审核。

| 资源 | 可参考内容 | 许可或使用依据 |
| --- | --- | --- |
| [OpenDSA Complete Catalog](https://opendsa.cs.vt.edu/OpenDSA/Books/Catalog/html/index.html) | 栈、队列、树、排序、图等章节的练习类型和可视化思路 | [OpenDSA MIT 许可](https://opendsa.org/home/license)；若复制实际题文，需保留版权及许可声明。当前项目只引用链接并自行编写摘要。 |
| [OpenDSA 官方仓库](https://github.com/OpenDSA/OpenDSA) | 公开题库系统和练习源码结构，可用于后续构建导入器 | 仓库提供 `MIT-license.txt`；具体子模块仍须单独核对许可证。 |
| [Open Data Structures](https://opendatastructures.org/) | 顺序表、链表、堆、树等理论核对 | CC BY；使用时应署名。 |

本项目的题目结构要求明确填写：知识点、目标误区、能区分掌握与误解的回答特征、参考答案、后续追问、难度和题型。教师页面新增题目时先存为 `DRAFT`；只有审核状态 `APPROVED` 才进入对话选题。审核人字段仅为本地操作记录，不等同于第三方认证的教学审核。
