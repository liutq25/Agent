## 下一个具体实现顺序

1. 由课程教师审定目录与诊断题；按 `python -m benchmark.review draft <文件>` 输出候选，审定至少 120 条后用 `python -m benchmark.review validate <文件>` 校验。公开资料不能代替教师审核或真实学生回答。
2. 将 22 个确定性算法工具的输入表单和首错解释逐一完善，并在聊天、练习和教师端统一呈现可复现证据。
3. 将现有回答、检索、工具、诊断和持久化节点逐步迁入现有 LangGraph，完成文档要求的完整图流程。
4. 用真实 Embedding 服务验证向量检索质量；做无诊断、无工具、无长期状态与完整系统的真实消融。
5. 补学生身份与班级权限，在真实教学中由教师审核诊断反馈与干预效果。
