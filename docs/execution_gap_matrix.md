## 下一个具体实现顺序

1. 由课程教师审定目录与诊断题，补齐课程资料来源；完成至少 120 条正式标注案例，并与 DEMO 数据分离。
2. 将 22 个确定性算法工具的输入表单和首错解释逐一完善，并在聊天、练习和教师端统一呈现可复现证据。
3. 将现有会话流程迁入 LangGraph checkpointer/interrupt，保留现有 SQLite 长期学生状态与 `diagnostic_trace` 审计事件。
4. 接入 Embedding 检索和课程资料引用；做无诊断、无工具、无长期状态与完整系统的真实消融。
5. 补教师权限与班级成员管理，在真实教学中由教师审核诊断反馈与干预效果。
